# SQE Lab 02 - Locating Web Elements

**Course:** Software Quality Engineering (SQE)  
**University:** Sindh Madressatul Islam University  
**Lab Instructor:** Hassan Raza  
**Tool:** Selenium WebDriver with Python

## Exercises

1. **Exercise 3:** Count links on Wikipedia using Tag Name.
2. **Exercise 4:** Locate a username field using ID, Name, and CSS Selector.
3. **Exercise 5:** Find text input elements using CSS Selector.
4. **Exercise 6:** Locate a table cell using XPath.

## Requirements

- Python 3
- Google Chrome
- Selenium WebDriver

## Install Selenium

```bash
python -m pip install -U selenium
```

## Run Programs

Run each Python file separately using VS Code terminal.

## Purpose

To understand and practice Selenium locator strategies for finding web elements on web pages.
